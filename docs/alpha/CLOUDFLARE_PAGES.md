# Независимый адрес для POPP Fitness Alpha

Подготовка относится к проверенной Alpha `8f248a93373e056350f7f439ec6c6ed552d4993d`
из `feature/smart-trainer-catalog-alpha`. Интерфейс и тренировочная логика не меняются.
Старый сайт, main, Supabase и настройки `@PocketCoachFitBot` остаются прежними.

20 ноября 2026 года, после отдельного разрешения владельца, Alpha опубликована:
[popp-fitness-alpha.pages.dev](https://popp-fitness-alpha.pages.dev/).
HTTPS проверен с проверкой сертификата. Все 10 файлов приложения на новом адресе
побайтово совпадают с проверенной сборкой `8f248a9`; одиннадцатый файл `_headers`
применён Cloudflare как конфигурация кеширования.

Размещение Cloudflare: `93affafc-f549-4949-a50b-8457e8905038`.
Отображаемая Cloudflare метка `Production / main` относится к Direct Upload:
Git-интеграции нет, ветка main репозитория не менялась.

## Что подготовлено

В папке `releases` лежит `popp-fitness-alpha-8f248a9.zip`. Он содержит только
готовую статическую сборку и правила кеширования `_headers`. `index.html`
находится в корне ZIP. Репозиторий, XLSX, журналы тренера, история пользователей,
`.env`, исходные тексты и зависимости в архив не входят.

Токен Telegram-бота для размещения этой Alpha не нужен. В Cloudflare не надо
добавлять его ни в переменные, ни в файлы. Frontend использует прежний официальный
Telegram SDK по HTTPS. Серверная авторизация Telegram и Supabase здесь не включаются.

Ручная загрузка ZIP выбрана как короткий путь: доступ к GitHub не нужен,
автоматических публикаций после коммитов нет. По правилам Cloudflare существующий
проект Direct Upload нельзя затем переключить на Git integration; для такой
интеграции создаётся отдельный проект.
[Документация Direct Upload](https://developers.cloudflare.com/pages/get-started/direct-upload/).

## Создать аккаунт

1. Открой [регистрацию Cloudflare](https://dash.cloudflare.com/sign-up).
2. Введи свою почту и придумай пароль самостоятельно.
3. Подтверди почту по письму. Если появится проверка входа, пройди её самостоятельно.
4. Перейди в панель управления. Покупать домен и подключать GitHub для этого пути не нужно.

На этом этапе ничего публиковать не требуется.

## Подготовить проект и опубликовать с разрешения

Создание пустого проекта и загрузка файлов готовят сайт, но не публикуют Alpha.
Шаг 5 выполняется только после отдельного разрешения владельца.

1. В Cloudflare открой **Workers & Pages** → **Create application**.
2. На экране создания выбери **Continue to Pages**, затем **Drag and drop your files** →
   **Get started**. Это Direct Upload без подключения Git-репозитория и создания Worker.
3. Укажи имя `popp-fitness-alpha`. Проверь адрес и нажми **Create project**.
4. Перетащи только подготовленный ZIP в область загрузки.
5. После разрешения владельца нажми **Deploy site** или **Save and Deploy** — это публичная публикация.
6. Скопируй фактическую ссылку `https://…pages.dev/`, показанную Cloudflare.

Используем основной адрес проекта без временного идентификатора сборки.
Адрес опубликованного сайта не должен вести обратно на прежний домен.

## Проверки опубликованного сайта

- HTTPS и все 10 файлов: HTTP 200, правильные типы содержимого, точное совпадение
  SHA-256 со сборкой `8f248a9`, без перехода на другой домен.
- 11 проверок в браузере: онбординг, пять направлений целей, три прежних рабочих
  варианта, явная недоступность силы и специализации спины без ложной записи профиля.
- Ввод дробного веса и повторений, восстановление точного черновика после полного
  перезапуска браузера, завершение и просмотр всех записанных подходов.
- Второй перезапуск сохранил историю и счётчик без дублирования завершения.
- Мобильные размеры 320/390/430 px: логотип, кнопки и выбор целей без переполнения;
  тренировка и история также проверены при 390 px.
- Ошибок приложения и неудачных сетевых загрузок не зафиксировано. Единственный
  внешний хост приложения — официальный `telegram.org`; SDK не подменялся.
- У HTML и ресурсов нет `X-Frame-Options: DENY` или блокирующего `frame-ancestors`.
  Ресурсы страницы загружаются по HTTPS.

Использовались только отдельные временные браузерные профили и синтетические
записи. История реальных пользователей и настройки бота не изменялись.

Настоящие Telegram iPhone/Android ещё не проверялись. Это отдельный следующий
шаг после разрешённого изменения адреса Mini App в `@PocketCoachFitBot`.

Telegram требует HTTPS URL для Web App:
[WebAppInfo](https://core.telegram.org/bots/api#webappinfo).
Подходящий тип адреса не заменяет проверку конкретной опубликованной ссылки.

## История при смене адреса

Данные localStorage привязаны к браузеру и адресу сайта. История со старого
домена автоматически не появится на `pages.dev`; новый домен начнёт с пустого
хранилища. Это не удаляет старую историю. Не очищай данные старого сайта и сохрани
его ссылку для просмотра прежних записей. Незавершённую тренировку лучше закончить
на прежнем адресе до перехода. Автоматического переноса или редиректа не добавляем.

## Повторить подготовку разработчику

Сначала убедись, что код приложения соответствует проверенному коммиту и нет
локальных `.env` с настройками сборки. Из корня репозитория:

```sh
cd client
npm run build
cd ..
python3 tools/deployment/package_cloudflare_pages.py --reviewed-commit 8f248a93373e056350f7f439ec6c6ed552d4993d
```

Скрипт не публикует сайт и не обращается к сети. Он проверяет файлы архива,
неизменность исходников относительно проверенного коммита, отсутствие похожих
на токен бота строк и старого домена в готовых файлах. Свежесть сборки обеспечивает
предшествующий `npm run build`. SHA-256 и список файлов находятся рядом с ZIP в JSON.

Правила кеширования добавляются только в пакет Cloudflare. Исходная сборка
приложения не переписывается. CSP и запрет iframe не добавлены.
[Как Pages обрабатывает заголовки](https://developers.cloudflare.com/pages/configuration/headers/).

Перед публикацией выполнена повторная проверка пакета на токены, приватные ключи,
почтовые адреса и недопустимые файлы: совпадений нет. Существующие результаты
369 тестов и 85 локальных браузерных проверок не выдаются за новый прогон:
приложение не менялось, на опубликованном сайте отдельно пройдены 11 проверок.

Отчёты: `cloudflare-preparation.json`, `cloudflare-prepublish-safety.json`,
`cloudflare-live-https.json`, `cloudflare-live-browser.json`.
Снимки опубликованного приложения: `cloudflare-screenshots/`.
