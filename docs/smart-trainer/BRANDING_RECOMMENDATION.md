# Название продукта: предварительный shortlist

Дата: **2026-11-13**. Новое имя не утверждено. POPP, package identity, assets,
bot username и URL остаются прежними. Следующий rebranding — отдельный commit
после решения владельца, не часть импорта.

## Границы исследования

Страны коммерческого запуска ещё не указаны; вопрос направлен владельцу.
Для языкового сравнения принята русскоязычная аудитория с латинским написанием.
Это не выбор юрисдикции. Риски в таблице — лингвистическая/продуктовая оценка,
а не результаты поиска товарных знаков или доказательство уникальности.

Попытки доступа к Pocket Coach (`https://www.pocketcoach.co/`), WIPO Brand DB
(`https://branddb.wipo.int/`), Роспатенту (`https://searchplatform.rospatent.gov.ru/`),
EUIPO (`https://euipo.europa.eu/eSearch/`) и USPTO (`https://tmsearch.uspto.gov/`)
получили `Tunnel connection failed: 403 Forbidden` на прокси. Никаких результатов
поиска внутри реестров получено не было. Проверки EU/US указаны как возможные
источники, не как подтверждение, что это целевые рынки.

Для каждого из семи .com выполнена попытка RDAP GET:
`https://rdap.verisign.com/com/v1/domain/<name>.com`. Все семь — тот же proxy 403.
Следовательно, **занятость каждого домена неизвестна**. Ошибка сети не означает
«домен свободен». Другие зоны, Telegram handles и app stores ещё не проверены.
Юридическую чистоту ни одного названия подтвердить нельзя.

## Pocket Coach

«По́кет ко́уч» / «карманный тренер» быстро объясняет продукт и подходит мобильному
формату. Владелец уже сообщил о совпадениях с фитнес-приложениями и coaching
сервисами; независимо проверить их в этой среде не удалось. Два общеупотребительных
английских слова дают слабую поисковую различимость и ожидаемо высокий риск
путаницы. Домен `pocketcoach.com` — **не проверен**, не предлагается как свободный.
Рекомендация: сохранить «карманный тренер» как возможное описание, Pocket Coach
не утверждать основным брендом до полноценного поиска.

## Шесть вариантов для выбора направления

| Написание | Произношение | Смысл / запоминаемость | Короткий URL-кандидат | Предварительный риск сходства |
| --- | --- | --- | --- | --- |
| **Ritmivo** | Ритми́во | Ритм + движение; 3 слога, передаёт регулярность, подходит шире зала | ritmivo.com, app.ritmivo.com | Неизвестен; общий корень ritm/rhythm, искать фонетические Ritmiva/Ritmio |
| **Setnora** | Сетно́ра | Set + вымышленное окончание; 3 слога, ассоциация с подходами | setnora.com | Неизвестен; gym-термин слабее отличает, возможны совпадения Nora/Setora |
| **Repvero** | Репве́ро | Rep + vero («настоящий»); акцент на реальных записях, 3 слога | repvero.com | Неизвестен; англ. rep неоднозначно, Vero распространённый элемент |
| **Formetra** | Форме́тра | Форма + мера; понятная русская ассоциация без обещания magic score | formetra.com | Неизвестен; form/metric распространены в health/measurement, нужен широкий поиск |
| **Trenavi** | Трена́ви | Тренировка + навигация; помощник по плану, 3 слога | trenavi.com | Неизвестен; проверить Trinavi/Trainavi и медицинские/туристические бренды |
| **Moventa** | Мове́нта | Move + движение вперёд; мягкое международное звучание | moventa.com | Неизвестен; особенно широкий поиск move/movent в wellness/transport/health |

Все варианты — рабочие предложения, не заявления о свободных словах. Длина .com
без зоны 7/7/7/8/7/7 символов. URL короткие по написанию; доступность, цена,
история домена и права не подтверждены. Ни один домен не куплен и не подключён.

Предварительный приоритет для языкового user test: **Ritmivo**, затем **Trenavi**.
Они объясняют ритм и сопровождение без обещаний измерения силы. Это только выбор
двух направлений для исследования; при конфликте реестра название исключается,
даже если нравится владельцу.

## Действия до утверждения

1. Владелец определяет страны, язык, юридического заявителя и shortlist 2–3 имён.
2. Проверить exact/phonetic/transliterated/semantic варианты в официальных
   национальных реестрах, WIPO и региональных реестрах выбранных стран. Обычно
   рассмотреть классы 9/41/42, а 44 — только по фактическим услугам; перечень
   классов и оценку конфликтов согласовать со специалистом по товарным знакам.
3. Проверить действующие продукты в Apple/Google stores, поиск, Telegram и
   social handles; отдельно разобрать Pocket Coach и pocketcoach/pocket-coach.
4. Выполнить RDAP/registrar проверку .com и целевых зон, premium/reserved status,
   историю и риски похожих доменов. Отсутствие DNS не доказывает доступность.
5. Записать ссылки/дату/заявителя/классы/статус каждого найденного сходства и
   решение, затем подтвердить название владельцем. Доступный домен не даёт прав
   на товарный знак.
6. Только затем отдельный rebranding commit и отдельное решение по хостингу,
   BotFather/URL. Смена origin требует сохранения старой localStorage истории:
   настройки DNS сами по себе не переносят данные.
