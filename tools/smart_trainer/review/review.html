Маршрут проверки тренера

  1. Обязательно: проверь десять основных упражнений и их справочники. В каждой карточке есть вопрос тренеру, назначения по фазам и переход к следующей зависимости.
  2. Программа: сверь восемь недель, дозировку, отдых и правила. Утверждение десяти упражнений само по себе не утверждает программу.
  3. Дополнительно: проверь замены, если планируешь их использовать. Они не нужны для проверки основных десяти. Для утверждения всей текущей программы по-прежнему нужны все включённые карточки, в том числе замены.

Решение по карточке

Одно решение охватывает явно перечисленный состав карточки: технику, биомеханику и её исходные связи. Общие определения проверяются как зависимости отдельно.

Комментарий обязателен для исправления, отклонения и заметки. Черновики остаются только до закрытия страницы. Подтверждение сохранения появляется после записи журнала на диск.
