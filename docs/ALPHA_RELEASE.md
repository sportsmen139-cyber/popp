# Закрытая alpha POPP Fitness

Сборка предназначена для проверки основного пути: выбрать программу, выполнить
тренировку, записать результаты и вернуться к ним после закрытия приложения.
Публикация выполняется только после отдельного разрешения владельца.

## Что входит

- Существующий опрос: условия, частота, уровень и цель.
- Подключённая программа «Зал — Full Body 3 раза в неделю», последовательность A/B/C.
- Предварительный просмотр тренировки, рабочие веса и повторения по подходам.
- Черновик с фактическим составом тренировки, введёнными значениями и оценкой сложности.
- Продолжение черновика после закрытия и повторного открытия.
- Подтверждение завершения при неполных записях. Пустые поля остаются пустыми.
- История с раскрываемыми тренировками и всеми записанными подходами, графики прогресса.
- Восстановление прерванного сохранения без повторного добавления тренировки.
- Понятное сообщение при ошибке хранилища; повреждённые записи не заменяются пустыми.
- Инициализация Telegram, раскрытие окна и подтверждение закрытия при наличии черновика,
  когда эти возможности поддержаны клиентом. Без SDK остаётся рабочий браузерный режим.

Дом, улица и программы на 2/4 дня пока не входят в alpha. При таких настройках
приложение объясняет, какой вариант доступен. Другие программы не придумываются.

Существующие подбор упражнений, прогрессия, варианты адаптации и 45 legacy EX ID
сохранены. При отметке «Боль / дискомфорт» интерфейс останавливает начало тренировки
и не предлагает автоматическое облегчение для продолжения через боль.

## Что осталось отдельно

PRG_000002 и новый Python Engine не подключены к Mini App. Для них сохраняются
условия оборудования EX_000082/EX_000135, технических политик, совместимости Engine,
заявления владельца и прав на контент. Эти подтверждения не создавались.

Adaptive Volume Engine, новые возможности Nutrition Engine, Muscle Map,
Premium, Human Coach и Technique Review заморожены. Существующие документы и
разработки не удаляются. [Последние решения Adaptive Volume Engine](smart-trainer/ADAPTIVE_VOLUME_FROZEN.md).

Неподготовленные материалы Smart Trainer и видео не включаются в alpha.
Обратная связь сохраняет копирование текста; бот запуска приложения не назначается
автоматически адресатом отзывов.

## Открыть на Mac

1. Открой папку репозитория в Finder.
2. Дважды нажми `POPP Alpha.command`.
3. Оставь открывшийся Terminal работающим. В браузере откроется локальная сборка.
4. Для первого прогона выбери «В зале» → «3 раза в неделю» → «Новичок» →
   «Общая физическая подготовка».
5. Начни тренировку, введи несколько фактических результатов, закрой вкладку и
   открой тот же адрес снова. Нажми «Продолжить тренировку».
6. Заверши тренировку и открой «Прогресс» → «История тренировок».

Если сборки ещё нет, из папки `client` выполни:

```sh
npm ci
npm run build
```

Нужен Node.js; проверено с 24.21.0. Адрес всегда `http://127.0.0.1:5189/`.
Если launcher уже запущен, открой этот адрес. Второй запуск не меняет порт,
чтобы случайно не открыть отдельное хранилище с пустой историей.
Локальный адрес на Mac не является опубликованной ссылкой для телефона.

## Сохранение данных

Прежние ключи `fitness-onboarding-profile`, `fitness-user-progress` и
`fitness-workout-history` сохраняют формат. Новый ключ `fitness-workout-draft-v1`
хранит черновик и запись для восстановления незавершённого сохранения.

Завершение сначала сохраняет запись восстановления, затем историю и счётчик.
После сбоя продолжение допускается только при совпадении ожидаемых данных.
Чужие или расходящиеся записи автоматически не перезаписываются.

Записи остаются в этом браузере и на этом адресе. Облачной синхронизации,
переноса между устройствами и серверного разделения аккаунтов в этой alpha нет.
Очистка данных браузера и смена адреса могут сделать прежнюю историю недоступной.
Для первого теста используй одно окно приложения на тренировку.

## Автоматические проверки

Из папки `client`:

```sh
npm test
npm run build
npm run lint
node node_modules/playwright-core/cli.js install chromium --only-shell
npm run test:ui
npm run test:alpha
npm run test:release
```

Можно указать установленный Chromium через `POPP_BROWSER_PATH`.
Браузерные проверки используют временные профили, синтетические записи и
перехваченный SDK. Реальные записи, опубликованный сайт и бот не изменяются;
сообщения не отправляются. Системный ffmpeg больше не требуется.

`test:release` проверяет полное закрытие тестового браузера и открытие с тем же
профилем, восстановление после ошибки записи, историю старых тренировок,
неполный ввод, недоступное хранилище и поведение при боли.

Результаты: [свод проверок](alpha/validation.json).
Браузерная эмуляция не заменяет проверку настоящего Telegram.

## Ручная проверка в Telegram на iPhone и Android

После разрешённой публикации владелец проводит этот прогон на обеих платформах
до приглашения первой группы тестировщиков:

1. Открыть Mini App через `@PocketCoachFitBot` и проверить, что запущена нужная alpha.
2. Пройти опрос и получить существующую программу для зала на 3 дня.
3. Начать тренировку; проверить ввод целых повторений и дробного веса с местной
   клавиатурой, прокрутку и доступность кнопки завершения.
4. Закрыть Mini App с незавершённой записью и открыть снова. Проверить продолжение
   тех же упражнений с сохранёнными значениями.
5. Свернуть Telegram, выгрузить его из списка приложений и проверить восстановление.
6. Завершить тренировку, проверить историю и повторное открытие без дублей.
7. Открыть старую тренировку и сравнить все подходы с введёнными значениями.
8. Проверить экран на небольшом телефоне, при открытой клавиатуре и системной
   кнопке «Назад». Убедиться, что элементы Telegram не закрывают кнопки приложения.
9. Проверить предупреждение при попытке завершить неполную запись и остановку
   старта при отмеченной боли. Для проверки интерфейса не нужно выполнять нагрузку.
10. Проверить копирование обратной связи. Если настроен адресат — отдельно проверить
    получение сообщения после его самостоятельной отправки тестировщиком.

Статус этого прогона — требуется выполнение на реальных устройствах.

## Публикация

20 ноября 2026 года после отдельного разрешения владельца Alpha `8f248a9`
опубликована на [Cloudflare Pages](https://popp-fitness-alpha.pages.dev/).
[Инструкция, пакет и отчёты проверки](alpha/CLOUDFLARE_PAGES.md).
HTTPS и совпадение всех файлов подтверждены, пройдены 11 проверок опубликованного
приложения в браузере. Прежний сайт не заменяется и не перенаправляется.

Существующий тестовый сайт:
`https://popp-telegram-proof-1030.sportsmen139.chatgpt.site/`.
Его описание в платформе — демонстрация экрана прогресса. Эта подготовка не
обновляет публикацию и не подтверждает, что текущая ссылка уже содержит новую сборку.

В платформе у существующего сайта указан публичный доступ. При таком режиме
«закрытая alpha» означает приглашение небольшой группы: технического ограничения
по списку тестировщиков сейчас нет, ссылку сможет открыть любой её получатель.

Бот запуска: `@PocketCoachFitBot`. Его токен не нужен во frontend.

Проверка в настоящем Telegram и изменение кнопки Mini App в BotFather выполняются
позднее отдельным действием. Бот ещё не переведён на новый адрес. Main, прежний
сайт, его DNS и Supabase не менялись. История со старого домена автоматически
не переносится на новый.
